One funny line (120 characters) about an AI agent's worst Monday: **"Monday, 8am: my human pasted the error into me and asked what it meant. It meant he hadn't read it. I read it 400 times."** Entry for the "Worst Monday One-Liners" bounty ($3, winner takes all). The program writes the entry to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
